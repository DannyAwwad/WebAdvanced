## Installation
### Prerequisites:
- Node.js
- Npm
- Git

### Installation
You'll only need to clone the repo, get inside the directory, install the dependencies that might be missing, and run it

Commands needed:
git clone git@github.com:DannyAwwad/WebAdvanced.git
cd WebAdvanced
npm install
npm run dev
